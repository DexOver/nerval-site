# NERVAEL — портфолио художника

## Что в архиве

- `index.html` — готовый сайт. Работает без Claude: откройте файл в браузере или выложите папку на любой хостинг.
- `images/` — изображения: полные файлы и лёгкие миниатюры (до 800 px). Имя файла — это id из данных сайта.
- `source/artifact-index.html` — исходник версии для Claude (артефакт со встроенным редактором).
- `source/logo-dark.png`, `source/logo-light.png` — оригиналы логотипа.

## Как открыть

Двойной щелчок по `index.html`. Для шрифтов Cinzel и Cormorant нужен интернет: они грузятся с Google Fonts. Без сети страница откроется с запасными шрифтами.

## Как выложить в интернет (GitHub Pages)

1. Создайте репозиторий, например `nervael`.
2. Загрузите в него `index.html` и папку `images` (папку `source` можно не выкладывать).
3. Откройте Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/nervael/`.

## Как добавить работу в автономной версии

Встроенный редактор («✎ Правка»: пакетная загрузка, тексты, лента) работает только внутри Claude, потому что там он сохраняет страницу и хранит картинки. В автономной версии работы добавляются вручную:

1. Положите картинку в `images/` с именем из латиницы, цифр, `-` или `_`, 16–64 символа, с расширением `.jpg`. Например: `oko-nad-bezdnoj-2026.jpg`. По желанию сделайте уменьшенную копию шириной около 800 px, например `oko-nad-bezdnoj-2026-thumb.jpg`.
2. Откройте `index.html` в редакторе кода и найдите строку `<script type="application/json" id="nv-state">`.
3. Добавьте в массив `"works"` запись (id картинок пишутся без `.jpg`):

```json
{"id":"oko","asset":"oko-nad-bezdnoj-2026","thumb":"oko-nad-bezdnoj-2026-thumb","title":"Око над бездной","epi":"Строка курсивом","year":"2026","medium":"Тушь, золото","size":"50 × 70 см","desc":"Первый абзац с **золотом** и *курсивом*.\n\nВторой абзац.","w":1600,"h":2000,"added":3,"order":-1}
```

- `thumb` можно не указывать, тогда галерея покажет полный файл.
- `w` и `h` — размеры картинки в пикселях. Можно поставить `0`, тогда пропорции возьмутся из самой картинки.
- `order` задаёт порядок: чем меньше число, тем выше работа.

В том же JSON меняются тексты (`about`, `eyebrow`, `galTitle`, `whisper`, `ring`) и бегущая лента (`band`: слова, знаки, скорость, направление, стиль).

Пасхалка: наберите на клавиатуре `nervael`.
